# Shared Libraries

Gemeinsam genutzte Maven-Module für alle Services.

| Library           | Beschreibung                                                 |
| ----------------- | ------------------------------------------------------------ |
| `shared-kernel`   | Domain Primitives, Base Entity, Audit-Felder, Tenant-Context |
| `event-contracts` | Event-Klassen und Schemas für die asynchrone Kommunikation (Kafka + RabbitMQ) |
