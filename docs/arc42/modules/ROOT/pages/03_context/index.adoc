== Fachlicher Kontext

Das Kontextdiagramm zeigt die Systemgrenzen und die wesentlichen externen Akteure. Die Blog-Funktionalität (STK-001) wird über eine REST API bereitgestellt, während Podcast- und Video-Inhalte (STK-009) über GraphQL angebunden werden.

== Technischer Kontext

[cols="1,1,2"]
|===
| Schnittstelle | Technologie | Beschreibung

| Blog REST API | HTTP/JSON | CRUD für Posts, Tags, Autoren (Thymeleaf + Angular)
| Podcast GraphQL API | HTTP/GraphQL | Queries/Mutations für Podcast-Episoden (React)
| Video GraphQL API | HTTP/GraphQL | Queries/Mutations für Video-Episoden (React)
| OpenRouter | HTTPS/JSON | KI-Funktionen (Übersetzung, TTS, Bildgenerierung)
| Kafka Events | Kafka Protocol | Asynchrone Service-Kommunikation
| RSS/Atom Feeds | HTTP/XML | Öffentliche Feeds für Reader
|===
