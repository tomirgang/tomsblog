== Post veröffentlichen und übersetzen

Das Sequenzdiagramm zeigt drei Abläufe, die zentrale Anforderungen abdecken:

1. **Veröffentlichung**: Autor veröffentlicht einen Post, Feed wird aktualisiert (SWR-002, SWR-008).
2. **KI-gestützte Übersetzung**: Autor löst Übersetzung aus, prüft den Vorschlag und übernimmt ihn (SWR-004, SWA-006).
3. **Manuelle Übersetzung**: Autor gibt die Übersetzung direkt ein (SWR-005).

== Post erstellen (vereinfacht)
