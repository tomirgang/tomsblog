== Post veröffentlichen und übersetzen

Das Sequenzdiagramm zeigt drei Abläufe:

1. **Veröffentlichung**: Autor veröffentlicht einen Post, Feed wird aktualisiert.
2. **KI-gestützte Übersetzung**: Autor löst Übersetzung aus, prüft den Vorschlag und übernimmt ihn.
3. **Manuelle Übersetzung**: Autor gibt die Übersetzung direkt ein.
