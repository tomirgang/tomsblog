11 Attachment Value Object mit show-Flag IMP011

Implementiert Attachment als Value Object (Java Record) mit AttachmentId, filename, contentType, size, show und storageKey. Factory-Methode create() generiert ID. Methode withStorageKey() erzeugt eine Kopie mit gesetztem Storage-Schluessel. show=true: Attachment wird im Blog-Rendering angezeigt (Galerie, Download). show=false: Attachment fuer eingebettete Inhalte (Inline-Bilder im Content). storageKey darf null sein (Datei noch nicht hochgeladen).
