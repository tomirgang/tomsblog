= Secrets-Management (SOPS + age)
:sectnums:

== Überblick

Secrets werden mit SOPS und age verschlüsselt im Git-Repository gespeichert (INF-004, ADR-0025). Flux entschlüsselt sie automatisch beim Deployment.

=== Architektur

[mermaid]
----
graph LR
    DEV[Entwickler] -->|sops --encrypt<br/>age Public Key| GIT[Git Repository<br/>verschlüsselte Secrets]
    GIT -->|Flux pull| KC[Kustomize Controller]
    KC -->|SOPS decrypt<br/>age Private Key| K8S[Kubernetes Secrets<br/>im Cluster]
----

== Verschlüsselungs-Workflow

=== Neues Secret erstellen

[source,bash]
----
# Secret-Manifest anlegen (Plaintext)
cat > infra/k8s/blog-content/secret.yaml << 'EOF'
apiVersion: v1
kind: Secret
metadata:
  name: blog-content-secrets
  namespace: tomsblog
type: Opaque
stringData:
  admin-password: "mein-geheimes-passwort"
EOF

# Mit SOPS verschlüsseln (age Public Key aus .sops.yaml)
sops --encrypt --in-place infra/k8s/blog-content/secret.yaml
----

=== Secret bearbeiten

[source,bash]
----
# Entschlüsselte Ansicht im Editor
sops infra/k8s/blog-content/secret.yaml
----

== SOPS-Konfiguration

Die Datei `.sops.yaml` im Repository-Root definiert, welche Dateien wie verschlüsselt werden:

[source,yaml]
----
creation_rules:
  - path_regex: infra/k8s/.*/secret\.yaml$
    age: "age1..."  # Public Key
    encrypted_regex: "^(data|stringData)$"
----

Nur die `data`/`stringData`-Felder werden verschlüsselt. Metadaten (Name, Namespace, Labels) bleiben lesbar.

== Flux-Entschlüsselung

Der private age-Schlüssel liegt als Kubernetes Secret im Cluster:

[source,yaml]
----
apiVersion: v1
kind: Secret
metadata:
  name: sops-age
  namespace: flux-system
type: Opaque
stringData:
  age.agekey: "AGE-SECRET-KEY-1..."
----

Dieses Secret wird einmalig manuell im Cluster erstellt (nicht im Git-Repository).

== Reflector: Cross-Namespace-Synchronisation

Für Secrets, die in mehreren Namespaces benötigt werden (z.B. PostgreSQL-Credentials), wird der Reflector-Operator eingesetzt (ADR-0025, SWA-020). Er synchronisiert annotierte Secrets automatisch in Ziel-Namespaces.
