= Image-Automation
:sectnums:

== Versionierte Image-Tags (INF-008)

Das Deployment verwendet Semantic Versioning (SemVer) Tags. Flux Image Automation überwacht die Container Registry und aktualisiert das Deployment-Manifest im Git-Repository automatisch, sobald eine neue Version veröffentlicht wird.

=== Tag-Schema

[cols="1,2,1"]
|===
| Variante | Format | Beispiel

| SemVer (Release) | `<major>.<minor>.<patch>` | `0.8.2`
|===

NOTE: CI-Builds erzeugen zusätzlich `sha-<hash>` Tags für Traceability, aber die Image-Automation verwendet ausschließlich SemVer-Tags.

=== Ablauf

[mermaid]
----
sequenceDiagram
    participant Dev as Entwickler
    participant GH as GitHub Actions
    participant GHCR as Container Registry
    participant FLUX as Flux Image Automation
    participant REPO as Git Repository
    participant K8S as Kubernetes

    Dev->>GH: Release-Tag (v0.8.2) pushen
    GH->>GH: Build & Test
    GH->>GHCR: docker push :0.8.2
    FLUX->>GHCR: Poll (alle 5 Min)
    FLUX->>FLUX: ImagePolicy: neuer SemVer-Tag erkannt
    FLUX->>REPO: git commit (deployment.yaml aktualisiert)
    FLUX->>K8S: Reconcile → Rolling Update
----

=== Deployment-Manifest

Das Deployment enthält einen Flux-Marker-Kommentar, der dem Image Automation Controller anzeigt, welches Feld aktualisiert werden soll:

[source,yaml]
----
containers:
  - name: blog-content
    image: ghcr.io/tomirgang/tomsblog/blog-content:0.8.2 # {"$imagepolicy": "flux-system:blog-content"}
----

=== Flux-Ressourcen (tomsblog/infra/k8s/flux-system/)

Die Image-Automation wird über drei Ressourcen im `tomsblog`-Repository konfiguriert:

* **ImageRepository** (`blog-content-image.yaml`) -- überwacht `ghcr.io/tomirgang/tomsblog/blog-content`
* **ImagePolicy** (`blog-content-image.yaml`) -- filtert Tags mit Muster `^\d+\.\d+\.\d+$` und wählt die höchste SemVer-Version (`>=0.1.0`)
* **ImageUpdateAutomation** (`blog-content-image-automation.yaml`) -- schreibt neue Tags in `infra/k8s/` zurück

=== Voraussetzungen

* Flux Image Reflector Controller und Image Automation Controller installiert (gotk-components)
* Git-Credentials-Secret `tomsblog-git-credentials` im Namespace `flux-system` (GitHub PAT mit `contents:write`)
* CI-Workflow taggt Images mit SemVer-Tag bei Release (docker/metadata-action `type=semver`)
