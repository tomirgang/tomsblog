= Image-Automation
:sectnums:

== Versionierte Image-Tags (INF-008)

Das Deployment verwendet versionierte Commit-SHA-Tags statt `latest`. Flux Image Automation überwacht die Container Registry und aktualisiert das Deployment-Manifest im Git-Repository automatisch.

=== Tag-Schema

[cols="1,2,1"]
|===
| Variante | Format | Beispiel

| Commit-SHA | `sha-<7-stelliger-hash>` | `sha-abc1234`
| Semver (bei Tags) | `<version>` | `0.5.2`
|===

=== Ablauf

[mermaid]
----
sequenceDiagram
    participant Dev as Entwickler
    participant GH as GitHub Actions
    participant GHCR as Container Registry
    participant FLUX as Flux Image Automation
    participant REPO as Git Repository
    participant K8S as Kubernetes

    Dev->>GH: Push auf main
    GH->>GH: Build & Test
    GH->>GHCR: docker push :sha-b015522
    FLUX->>GHCR: Poll (alle 5 Min)
    FLUX->>FLUX: ImagePolicy: neuer sha-Tag erkannt
    FLUX->>REPO: git commit (deployment.yaml aktualisiert)
    FLUX->>K8S: Reconcile → Rolling Update
----

=== Deployment-Manifest

Das Deployment enthält einen Flux-Marker-Kommentar, der dem Image Automation Controller anzeigt, welches Feld aktualisiert werden soll:

[source,yaml]
----
containers:
  - name: blog-content
    image: ghcr.io/tomirgang/tomsblog/blog-content:sha-b015522 # {"$imagepolicy": "flux-system:blog-content"}
----

=== Flux-Ressourcen (kubernetes-playground)

Die Image-Automation wird über drei Ressourcen konfiguriert:

* **ImageRepository** (`blog-content-image.yaml`) -- überwacht `ghcr.io/tomirgang/tomsblog/blog-content`
* **ImagePolicy** (`blog-content-image.yaml`) -- filtert Tags mit Muster `^sha-[a-f0-9]\{7}$`
* **ImageUpdateAutomation** (`blog-content-image-automation.yaml`) -- schreibt neue Tags in `infra/k8s/` zurück

=== Voraussetzungen

* Flux Image Reflector Controller und Image Automation Controller installiert (gotk-components)
* Git-Credentials-Secret `tomsblog-git-credentials` im Namespace `flux-system` (GitHub PAT mit `contents:write`)
* CI-Workflow taggt Images mit `type=sha` (docker/metadata-action)
