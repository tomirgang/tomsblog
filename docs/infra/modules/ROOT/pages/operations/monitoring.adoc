== Aktuelle Observability

Bis Phase 9 stehen folgende Mittel zur Verfügung:

* **Health-Checks**: Kubernetes Liveness/Readiness Probes (`/actuator/health`)
* **Flux Status**: `flux get all` zeigt den Reconciliation-Status
* **kubectl**: Manuelle Inspektion von Pods, Events, Logs
* **Linkerd Dashboard**: `linkerd viz dashboard` (falls Viz-Extension installiert)

=== Manuelle Log-Inspektion

[source,bash]
----
# Logs des blog-content Pods
kubectl logs -n tomsblog deployment/blog-content -f

# Events im Namespace
kubectl get events -n tomsblog --sort-by='.lastTimestamp'

# Flux-Fehler
flux get kustomizations
flux logs --level=error
----
