= Network Policies
:sectnums:

== Default-Deny-Strategie

Alle Namespaces verwenden eine Default-Deny NetworkPolicy (INF-007). Nur explizit erlaubte Verbindungen sind möglich.

=== Default-Deny

[source,yaml]
----
apiVersion: networking.k8s.io/v1
kind: NetworkPolicy
metadata:
  name: default-deny
  namespace: tomsblog
spec:
  podSelector: {}
  policyTypes:
    - Ingress
    - Egress
----

=== Ingress-Policies

[cols="1,2,2"]
|===
| Policy | Erlaubt von | Erlaubt zu

| network-policy-ingress | Traefik (kube-system) | blog-content :8080
| network-policy-acme-solver | cert-manager Solver Pods | Traefik :80
| network-policy-intra | Pods im selben Namespace | Alle Ports (intern)
|===

=== Egress-Policies

[cols="1,2,2"]
|===

|===

== Dateien im Repository

Alle Network Policies liegen unter `infra/k8s/blog-content/`:

* `network-policy-deny.yaml` -- Default Deny (Ingress + Egress)
* `network-policy-ingress.yaml` -- Erlaubt Traefik-Zugriff
* `network-policy-acme-solver.yaml` -- Erlaubt ACME-Challenge
* `network-policy-intra.yaml` -- Erlaubt Namespace-interne Kommunikation
* `network-policy-egress.yaml` -- Erlaubt ausgehende Verbindungen
