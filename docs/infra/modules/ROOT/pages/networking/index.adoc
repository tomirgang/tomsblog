== Überblick

Der externe Zugang zur Plattform erfolgt über den Traefik Ingress Controller mit automatischer TLS-Terminierung (INF-003). Innerhalb des Clusters regeln Network Policies den erlaubten Traffic (INF-007).

=== Traffic-Flow

Das folgende Diagramm zeigt den vollständigen Pfad eines HTTP-Requests:

[mermaid]
----
sequenceDiagram
    participant C as Client (Browser)
    participant LB as Hetzner LB
    participant T as Traefik
    participant MW as Middleware<br/>(Redirect HTTPS)
    participant LP as Linkerd Proxy
    participant BC as blog-content

    C->>LB: HTTPS (blog.tomirgang.de)
    LB->>T: TCP Passthrough :443
    T->>T: TLS Terminierung (cert-manager Cert)
    T->>LP: HTTP → mTLS (Linkerd)
    LP->>BC: HTTP :8080
    BC-->>C: Response (gleicher Pfad zurück)
----
