= Cluster-Setup
:sectnums:

== Überblick

Das Kubernetes-Cluster bildet die Laufzeitumgebung für alle Toms-Blog-Services (INF-001). Es wird auf Hetzner Cloud mit dem CLI-Tool https://github.com/vitobotta/hetzner-k3s[hetzner-k3s] provisioniert (ADR-0034).

Die Cluster-Provisionierung liegt in einem separaten Repository (`kubernetes-playground/k3s/`), getrennt von den applikationsspezifischen Ressourcen in diesem Repository.

=== Cluster-Parameter

[cols="1,2"]
|===
| Parameter | Wert

| Distribution | k3s (via hetzner-k3s)
| Controller | 1x CPX22 (2 vCPU, 4 GB), Nürnberg (nbg1)
| Worker Nodes | 2x CPX22 (2 vCPU, 4 GB), Nürnberg (nbg1)
| CNI | Flannel (k3s-Standard)
| Privates Netzwerk | 10.0.0.0/16
| Storage | Hetzner CSI (hcloud-volumes)
| Ingress | Traefik (k3s-Standard)
| Basis-Domain | cluster.tomirgang.de
| Kosten | ca. 26 EUR/Monat (3x CPX22 + Volumes + IPs)
|===

[cols="1,1,2"]
|===
| Namespace | Verwaltet durch | Inhalt

| `kube-system` | k3s / IaC | Traefik, CoreDNS, Metrics Server
| `flux-system` | IaC | Flux Controller (Source, Kustomize, Helm)
| `cert-manager` | Flux (Operator) + App (Issuer) | cert-manager Operator, ClusterIssuer
| `linkerd` | IaC | Linkerd Control Plane
| `postgres` | App (infra/k8s/postgres/) | CloudNativePG Cluster
| `tomsblog` | App (infra/k8s/blog-content/) | Application Workloads
|===
