11. Risiken und technische Schulden

1. Bekannte Risiken

ID Risiko Mitigation Prio

R-01

Ein-Personen-Projekt: Bussfaktor = 1

Gute Dokumentation (arc42, ADRs), AI-Agent-Unterstützung

Mittel

R-02

Java 25 ist sehr neu, manche Libraries haben noch Kompatibilitätsprobleme

Maven/Tooling-Warnungen akzeptieren, Fallback auf Java 21 möglich

Niedrig

R-03

Kafka-Betrieb auf kleinem Cluster ist aufwändig

Strimzi Operator, initial single-node Kafka (KRaft)

Mittel

R-04

OpenRouter-Abhängigkeit für KI-Features

Graceful Degradation: KI-Features optional, Fallback auf manuell

Niedrig

R-05

Zwei Messaging-Systeme erhöhen Betriebskomplexität

Klare Verantwortungstrennung (Events vs. Jobs), Kubernetes-Operatoren für beide, einheitliches Monitoring

Niedrig
