2. Randbedingungen

1. Technische Randbedingungen

Randbedingung Erläuterung

Java 25

Neuestes LTS, lokal installiert

Maven

Build-System (Multi-Module, Parent POM mit Spring Boot Starter)

Spring Boot 3.4.x

Framework für alle Microservices

PostgreSQL / MongoDB

Database per Service: Technologiewahl pro Service (CloudNativePG / MongoDB Operator)

Apache Kafka

Event-Broker für Domain Events (KRaft-Mode, Strimzi auf K8s)

RabbitMQ

Task-Queue-Broker für Job-Verteilung (Quorum Queues, RabbitMQ Cluster Operator)

Kubernetes

Deployment-Plattform (Hetzner, 3-Node-Cluster)

Docker

Container-Runtime und lokale Entwicklungsumgebung

2. Organisatorische Randbedingungen

Randbedingung Erläuterung

Ein-Personen-Projekt

Alle Rollen in einer Person (Dev, Ops, Architect)

Lernprojekt

Technologie-Entscheidungen dürfen Lernwert priorisieren

Budget-limitiert

Hetzner Cloud, Netcup VM (kein Enterprise-Tooling)

Open Source

Apache License 2.0
